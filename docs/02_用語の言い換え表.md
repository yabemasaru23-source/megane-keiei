# 用語の言い換え表

「思いこみメガネをはずす経営」では、マネジメントの専門用語を、小学生でもわかる言葉に言い換えます。
本文では**新しい呼び名**を使い、もとの言葉は必要なときだけ「（マネジメントの言葉では〇〇といいます）」と一度だけ添えます。

## 全体

| もとの言葉 | 新しい呼び名 | ひとことで言うと |
|---|---|---|
| 識学 | （使わない）この教材が参考にした考え方 | — |
| 錯覚 | **思いこみメガネ** | 本当とちがう見え方をさせる、心のメガネ |
| 意識構造 | 心のしくみ | 人がどう感じて、どう動くかのしくみ |
| 事実と認識のズレ | 「本当」と「そう見えている」のズレ | |
| 組織の生産性 | チームの力 | 同じ人数で、どれだけ大きなことができるか |
| マネジメント | チームの動かし方 | |

## 立場とルール

| もとの言葉 | 新しい呼び名 | ひとことで言うと |
|---|---|---|
| 位置（ポジション） | **自分の席** | チームの中で、自分はどこに座っていて、だれに報告するのか |
| 指揮命令系統 | 報告の道すじ | 「だれから仕事を受けて、だれに返すか」の一本道 |
| 姿勢のルール | **だれでも守れる約束** | 能力に関係なく、やる気があればだれでもできる約束（挨拶・しめきり・報告） |
| 行動のルール | 仕事の進め方の約束 | その仕事をするときの手順や決まりごと |
| ルールの明文化 | 約束を紙に書く | 「言わなくてもわかる」をやめる |
| 責任 | **任された範囲** | 自分が「できあがり」まで届ける約束をした仕事 |
| 権限 | **使える道具** | 任された仕事のために、自分で決めてよいこと・使ってよいもの |

## 結果と評価

| もとの言葉 | 新しい呼び名 | ひとことで言うと |
|---|---|---|
| 完全結果 | **ゴールテープ（できあがりの姿）** | 「これができていたら合格」と、だれが見ても同じに判断できる姿 |
| 期日・期限 | しめきり | 日付と時刻まで決める |
| 成果物 | 提出物 | できあがりを確かめるための「もの」 |
| 結果評価 | **点数は「できあがり」でつける** | がんばりではなく、届けたもので点数をつける |
| プロセス評価 | 「がんばったね」点数 | やり方やがんばりにつける点数（この教材ではおすすめしない理由を説明する） |
| 評価者 | 点数をつける人 | 自分の席の一つ上の人 |
| 免責 | **「でも・だって」の逃げ道** | 「できなかったのは自分のせいじゃない」と言える、すきま |
| 言い訳 | 「でも・だって」 | |
| 不足 | 伸びしろ | まだ足りないところ。成長の入り口 |
| 成長 | 階段を1段のぼる | できなかったことが、できるようになること |

## 上司と部下

| もとの言葉 | 新しい呼び名 | ひとことで言うと |
|---|---|---|
| 距離感 | **ちょうどいい距離** | 仲よしすぎず、遠すぎず。上司が「友だち」になると点数がつけられなくなる |
| 主張 | 気持ち・意見 | 「〜だと思う」「たぶん」 |
| 事実 | 事実 | だれが見ても同じこと（数字・日付・起きたこと） |
| 報連相 | 報告のかたち | 結論 → 事実 → 理由 → 次にやること |
| 組織の利益 | チームの勝ち | |
| 個人の利益 | 自分の勝ち | 給料・ほめられる・できることが増える |
| 競争環境 | いい意味のライバル | となりの人と比べられるから、伸びる |
| 成長シート | **わが社の成長シート** | 役職ごとに「何を・いつまでに・どのくらい」を書いた1枚の表 |

## 成長シートの4つの段

| もとの言葉 | 新しい呼び名 | 自分に聞く質問 |
|---|---|---|
| 期待成果 | チームに届けるできあがり | この席の人が、チームに届けるいちばん大事なものは？ |
| 重要業務 | 大事な仕事 | そのために、毎月かならずやる仕事は？ |
| 知識・技術 | 知っておくこと・できること | その仕事のために、身につけることは？ |
| 姿勢（勤務態度） | 毎日の約束 | だれでも守れる約束を、守れているか？ |

## 5段階の基準（全章共通）

| 段 | 呼び名 | めやす |
|---|---|---|
| 1 | まだ | できあがりを、しめきりまでにほとんど届けられていない |
| 2 | ときどき | 声をかけられると、できることがある |
| 3 | できる | しめきりまでに、できあがりを届けられる |
| 4 | いつもできる | 声をかけられなくても、毎回届けられる |
| 5 | お手本 | ほかの人に教えられる。チームのお手本になっている |

※数字の割合（何割届けたか）を使う場合は、第5章で「何の何割か」を言葉で決めてから使います。
