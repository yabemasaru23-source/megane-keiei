# 思いこみメガネをはずす経営 学習コンテンツ 設計書（v0.1）

作成日：2026-10-04
対象：識学の考え方（意識構造・錯覚をなくすマネジメント）を、オリジナルの言葉で学べるWeb教材にする

---

## 1. この設計書の目的

識学で学ぶ「事実と思いこみのズレをなくして、組織がまっすぐ動くようにする」考え方を、
**小学生でもわかる言葉とたとえ話**で、誰でも一人で学べるWeb教材にするための設計図です。

- 兄弟の教材「会社が自走する仕組みづくり」（`shikumi-keiei/`）と**同じ画面の作り**を使い回します
- 文章・設問・記入例は**すべて書き下ろし**です。識学の書籍・研修資料の文章は転載しません
- 「識学」は株式会社識学の登録商標です。サイトでは「識学公式」とは名のらず、必要なときだけ
  「参考にした考え方」として一度だけ触れます

## 2. 元資料（成長シート.xlsx）の読み込み結果

| シート | 中身 | 教材での扱い |
|---|---|---|
| スタッフ向け／一般職／管理職／幹部向け | 役職ごとの成長シート。「期待成果・重要業務・知識技術・姿勢のルール」を、成果物・期日・5段階の基準で並べたもの | **形（表の骨組み）だけ**を第10章のワークに使う。中身はすべて架空企業で書き直す |
| Sheet1 | マニュアル作りの担当者表と工程 | **使わない**（実在の方のお名前があるため） |

### 元資料のよいところ
- 「何を・いつまでに・どうなっていたら合格か」が表になっている（あいまいさがない）
- 挨拶や報告の仕方まで「誰でもできる約束」として書かれている
- 役職が上がるほど、求められる「できあがり」が大きくなる

### 元資料の困りごと（教材で解決すること）
| # | 困りごと | 教材での解決 |
|---|---|---|
| 1 | **なぜこの表なのか**が書かれていない | 第0〜9章で考え方を学んでから、第10章で表を作る |
| 2 | 5段階の基準が「40%以下・60%以上…」と数字だけで、何の割合かわかりにくい | 「できあがりの何割を、しめきりまでに届けたか」と言葉で決める |
| 3 | 姿勢のルールが4枚すべてに同じ文でくり返されている | 「全員共通の約束」と「役職ごとの約束」に分ける |
| 4 | 業界の専門用語（介護の業務名・システム名）が多い | 架空のパン屋さんで、誰でもわかる仕事に置きかえる |
| 5 | 表を作ったあと、どう使うか（面談・ふり返り）がない | 第11章で「90日まわす」手順を作る |

## 3. 作り直しの基本方針（5原則）

1. **思いこみメガネを1つずつはずす**：各章で「よくある思いこみ」を1つ取り上げ、「本当はこう」と事実を見せる
2. **2つのコースに分ける**：ルールや成長シートを**つくる人**（経営者・管理職）と、それを**使う人**（社員）では、知りたいことが違う
3. **1章＝同じ型**：「思いこみ → 本当は → たとえ話 → 考え方 → ワーク → 完成物 → チェック」でそろえる
4. **最後に1枚の表になる**：経営者・管理職コースでは、全章の答えが第10章の「わが社の成長シート」に集まる
5. **記入例は架空の1社で通す**：パン屋さん「こむぎベーカリー」で全章の記入例を見せる

## 4. 全体構成（2コース・12章＋社員コース5章）

### 4-1. 経営者・管理職コース（つくる人）

★＝必修（この7章で「わが社の成長シート」と運用の手順ができあがる）

| 章 | タイトル | 必修 | はずす思いこみメガネ | 参考にした考え方 | この章の完成物 | 目安 |
|---|---|:-:|---|---|---|---|
| 0 | 思いこみメガネをはずそう | ★ | 「みんな同じものを見ているはず」 | 錯覚・意識構造 | わが社のモヤモヤ診断（20問） | 20分 |
| 1 | 自分の席はどこ？ | ★ | 「上司と部下は、なかよしの横並びがいい」 | 位置（立場） | わが社の「席の地図」（だれが・だれに報告するか） | 60分 |
| 2 | チームのルールブック | ★ | 「言わなくても、ふつうはわかる」 | 姿勢のルール・行動のルール | だれでも守れる約束10個 | 60分 |
| 3 | 任された範囲と使える道具 | | 「全部まかせた（でも口は出す）」 | 責任と権限 | 役職ごとの「任せる・決めていい」表 | 45分 |
| 4 | ゴールテープを先に引く | ★ | 「がんばってね、で伝わる」 | 完全結果・期日 | 仕事の「できあがり＋しめきり」の書き方10本 | 60分 |
| 5 | 点数は「できあがり」でつける | ★ | 「がんばった人をほめるのがいい評価」 | 結果で評価・評価者は上司 | 点数のつけ方のルール（5段階） | 60分 |
| 6 | 「でも・だって」の逃げ道をふさぐ | | 「言い訳を聞いてあげるのがやさしさ」 | 免責をなくす | 言い訳が生まれる「すきま」の点検表 | 45分 |
| 7 | 上司と部下のちょうどいい距離 | | 「仲がよいほど、チームは強い」 | 距離感 | 上司の「やる・やらない」宣言 | 45分 |
| 8 | 「気持ち」と「事実」を分けて話す | | 「熱く話せば伝わる」 | 主張と事実・報告の型 | わが社の報告のかたち（4ステップ） | 45分 |
| 9 | チームが勝つと自分も勝つ | | 「自分のためにがんばる人は、わがまま」 | 組織の利益と個人の利益・競争 | チームの勝ちと自分の勝ちのつながり図 | 45分 |
| 10 | わが社の成長シートをつくる | ★ | 「人を育てるのはセンス」 | 成長シート（元資料の形） | 役職ごとの成長シート | 120分 |
| 11 | 90日まわしてみよう | ★ | 「表を作ったら終わり」 | 運用・面談・ふり返り | 90日の運用カレンダー＋面談の台本 | 45分 |

- **必修7章の合計は約7時間**です。月2回のセッションなら約3か月で完成します
- 第10章では、それまでの章の答え（席の地図・約束・できあがり・点数のつけ方）が**自動で表に入ります**

### 4-2. 社員コース（使う人）

ルールや評価を「受ける側」が、**こわがらずに、前向きに**使えるようになるための入門です。
入力欄は少なめで、読んで・クイズに答えて・自分の目標を1つ書く形にします。

| 章 | タイトル | 中身 | 目安 |
|---|---|---|---|
| S0 | 思いこみメガネってなに？ | 第0章のやさしい版。クイズ5問 | 15分 |
| S1 | ルールは「自分を守る」ためにある | 席・ルール・任された範囲。ルールがあると迷わない・責められない | 20分 |
| S2 | ゴールテープとしめきりを確かめよう | 仕事を受けたときに確かめる3つの質問（何を・いつまでに・どうなっていたら） | 20分 |
| S3 | 報告は「事実」から | 結論→事実→次にやること。「でも・だって」を「次は〜します」に言いかえる練習 | 20分 |
| S4 | 成長シートの使いかた | 自分の成長シートの読み方、次の90日で1段上がる目標を1つ書く | 20分 |

- 合計約1時間30分。新人研修・朝礼・全体会議でそのまま使えます
- 経営者・管理職コースの章とリンクでつなぎ、「上司はこういう考えで作っています」が見えるようにします

## 5. 1章の標準フォーマット（全章共通）

```
┌─────────────────────────────────────────┐
│ ① この章でできるようになること（3行）          │
│ ② 思いこみメガネ（よくある思いこみ）→ 本当は    │ ← この教材ならではの入口
│ ③ たとえ話（学校・家・スポーツ・パン屋さん）     │ ← 小学生でもイメージできる場面
│ ④ 考え方（図1枚＋解説 800〜1500字）            │
│ ⑤ ワーク（3〜6問・ヒントと記入例つき）          │
│ ⑥ 完成物（入力内容から自動でまとまる）          │
│ ⑦ セルフチェック（5項目）                      │
│ ⑧ 次の章とのつながり                           │
│ ⑨ 講師ガイド（時間配分・問いかけ例・つまずき）    │
└─────────────────────────────────────────┘
```

社員コースは ①②③④ と「クイズ」「自分の目標1つ」だけの短い型にします。

### セルフチェックの例（第4章 ゴールテープを先に引く）
- [ ] 「できあがり」は、見た人がだれでも同じ判断ができる言葉になっているか（「しっかり」「きちんと」を使っていない）
- [ ] しめきりは「日付と時刻」まで書いてあるか
- [ ] 「どうやるか」まで上司が決めすぎていないか（やり方は任せる）
- [ ] できあがりを、数字・状態・提出物のどれかで確かめられるか
- [ ] 部下が「わかりました」だけでなく、自分の言葉で言いなおせたか

## 9. 著作権・商標・表現のルール

| 区分 | 扱い |
|---|---|
| 識学の書籍・研修資料・Webサイトの文章 | **転載しない**。考え方の骨組みだけを参考に、ゼロから書き直す |
| 「識学」という名前 | サイト名・章名・見出しには使わない。「この教材が参考にした考え方」として一度だけ触れる |
| 元資料（成長シート）の中身 | 業務名・期日・ルールの文は**使わない**。表の骨組み（4つの段・5段階）だけ参考にする |
| 元資料の担当者名（Sheet1） | **一切使わない** |
| 実在の企業名・人名 | **載せない** |
| モヤモヤ診断・クイズ | 設問はすべてオリジナルで新しく作る |

## 10. Webシステム

「会社が自走する仕組みづくり」の仕組み（`assets/app.js`・`app.css`）をコピーして使います。

| 機能 | 内容 |
|---|---|
| 学習サイト | トップにコースの入口が2つ（「つくる人」「使う人」） |
| ワーク入力 | 自動保存（各自のブラウザの中）、JSON・Excel書き出し、印刷 |
| まとめページ | 「わが社の成長シート」を役職ごとに1枚の表で表示・印刷 |
| 公開 | GitHub Pages（新しいリポジトリ。例：`megane-keiei`） |

追加する入力欄の種類：
- `quiz`：社員コースのクイズ（答えを選ぶと、ミルルが解説）
- `growthsheet`：成長シートの表（4つの段×項目×5段階）。前の章の答えが自動で入る
