# 挿絵・図のルール

「思いこみメガネをはずす経営」の挿絵と図は、すべて手書きのSVGで作ります。
サイトではSVGをページに直接埋めこむので、色の指定（CSS変数）がライト／ダークの両方に効きます。

## 見本（必ず最初に見る）
- `assets/img/miruru.svg` … 案内役「ミルル」（まるいメガネのフクロウ。思いこみメガネをはずす象徴）
- `assets/img/ch10-cover.svg` … 章の扉絵の見本（800×320）
- `assets/img/ch10-tree.svg` … 図解の見本（800×470）

## 種類とサイズ
| 種類 | ファイル名 | viewBox | 中身 |
|---|---|---|---|
| 扉絵 | `chNN-cover.svg` | 0 0 800 320 | 章のたとえ話をひと目で伝える情景。ミルルが必ず登場し、ひとことの吹き出しを言う |
| 図解 | `chNN-xxxx.svg` | 幅800・高さは自由（300〜520） | 考え方の流れ・しくみ。文字で描いた図（```ブロック）を置きかえる |

## 色（必ず `var(--名前, 予備の色)` の形で書く）
| 変数 | 予備の色 | 使いどころ |
|---|---|---|
| --ink | #1d2540 | 線・文字 |
| --ink-soft | #545c78 | 補足の文字・矢印 |
| --surface | #fff | 吹き出し・白い面 |
| --sky | #dbe7fb | 扉絵の背景・空 |
| --sky-ink | #6f86b8 | 山・遠景 |
| --sun | #f2b01e | 主役（ゴール・大事なもの） |
| --sun-soft | #fdf0cc | 主役のうすい面 |
| --leaf | #2f8f6b | 丘・「できた」 |
| --leaf-soft | #dcf1e8 | 仕組み・うすい緑の面 |
| --warm | #c0583a | 屋根・ポイントの赤 |

- 濃い背景の色（--sun）の上に置く文字だけは、固定の `#1d2540` にする。うすい色（--sun-soft・--sky・--leaf-soft など）の上の文字は `var(--ink, #1d2540)` にする（ダークモードでうすい色が暗くなるため）
- ミルルの顔の色（#1d2540, #ffd866, #f4845f, #fff）は固定色のままでよい

## 描き方
- 線は太め（2〜3px）、角は丸く（stroke-linecap / stroke-linejoin は round）
- 平らな塗り。グラデーション・影・写真風は使わない
- 文字は `font-family="Zen Maru Gothic, sans-serif"`、太さ700。大きさは12〜20
- 文字はすべて日本語で、小学生でも読める言葉。用語は `docs/02_用語の言い換え表.md` にそろえる
- 絵文字は図の中でアイコンとして使ってよい（1か所に1つまで）
- `id` を使うときは、必ず `c10-` のように章番号で始める（ページ内で重ならないように）
- 必ず `role="img"` と、絵の内容を説明する `aria-label` をつける
- ファイルは30KB以内。細かい模様や長いパスは使わない

## Markdown への入れ方
- 扉絵：frontmatter に `cover: "ch10-cover.svg"` を書く
- 図解：本文に `![説明の文](assets/img/ch10-tree.svg)` と書く（1行だけで、前後に空行）
