# 思いこみメガネをはずす経営

チームのモヤモヤは、だれかのせいではなく「見え方のズレ」から生まれる。
思いこみメガネを1つずつはずして、だれが見ても同じ「ゴールテープ」と「成長シート」をつくる学習ワークサイトです。

- つくる人のコース（社長・管理職）：第0〜11章。最後に「わが社の成長シート」ができあがります
- 使う人のコース（社員さん）：S0〜S4（準備中）
- 入力した内容は、見ている人のブラウザの中だけに自動保存されます（サーバーには送られません）

## フォルダ構成

```
megane-keiei/
├─ index.html
├─ assets/          app.css・app.js（「会社が自走する仕組みづくり」と同じ仕組み）、img/ 挿絵
├─ content/
│   ├─ chapters.json   章の一覧（章を追加したら "file" にファイル名を書く）
│   ├─ chapters/       各章の本文（Markdown）
│   └─ example/        記入例の架空企業「こむぎベーカリー」
└─ docs/            設計書・用語の言い換え表
```

文章の直し方・入力欄の書き方は、兄弟サイト `shikumi-keiei/README.md` と同じです。

## パソコンで試しに見るには

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## 著作権・商標について

本教材の文章・設問・記入例は、すべてオリジナルで書き下ろしたものです。
マネジメント理論「識学」（株式会社識学の登録商標）の考え方を参考にしていますが、同社の公式教材ではなく、同社の資料の文章は使用していません。
記入例に登場する「こむぎベーカリー株式会社」と人物は架空であり、実在の企業・人物とは関係ありません。
