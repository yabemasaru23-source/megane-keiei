## ① この章でできるようになること

- チームのモヤモヤの正体が「思いこみメガネ」だとわかり、自分の言葉で説明できるようになる
- これから進む章の地図と、どの順番で進めばいいかがわかる
- 自分の会社のどこにメガネのくもりがあるかを点数で知り、どこから始めればいいかがわかる

## ② 思いこみメガネ、かけていませんか？

> 🦉 **思いこみメガネ**
> 「同じ会社で、同じ言葉を使っているんだから、みんな同じものを見ているはず」

### こんなこと、ありませんか？

- 「ちゃんとやってね」と頼んだのに、できあがってきたものが思っていたのとちがう
- 「言ったよね？」「聞いてません」の言い合いが、月に何度もおきる
- まじめな社員さんほど「どうせ評価されない」と元気をなくしていく
- 失敗の報告が、いつも「でも…」「だって…」から始まる
- 社長が見ていないところで、やり方がどんどんバラバラになっていく

私がこれまで多くの社長さんとお話ししてきて、本当によく聞く悩みです。
そして、こういう話をするとき、多くの社長さんはこう言います。

「うちの社員は、やる気がなくて…」

でも、私はそうは思いません。**ほとんどの場合、だれも悪くないんです。**
社長も社員さんも、それぞれ一生けんめいです。ただ、**同じものを見ているつもりで、ちがうものを見ている**。
このズレが、チームのモヤモヤの正体です。

> 🦉 **本当は…**
> 人はみんな、自分だけの「思いこみメガネ」をかけて世界を見ている。
> だから、**言葉にして、形にして、そろえないかぎり、同じものは見えない。**

### 目指す姿

| いま（メガネがくもったチーム） | 目指す姿（メガネをはずしたチーム） |
|---|---|
| 「ちゃんと」「しっかり」で仕事を頼み、できあがりが人によってちがう | 「何を・いつまでに・どうなっていたら合格か」が、頼んだときにそろっている |
| だれに報告すればいいのか、だれの言うことを聞けばいいのか、迷う | 自分の席と報告先がはっきりしていて、迷わない |
| がんばっても、がんばらなくても、点数があまり変わらない | 届けたできあがりで点数がつくので、成長が見える |
| 失敗すると「でも・だって」と言いたくなる | 「次はこうします」と言える。ルールがあるから責められない |
| 社長が見ていないと、やり方がバラバラになる | 約束が紙に書いてあるので、社長がいなくてもそろう |

## ③ たとえ話：「お部屋をきれいにしてね」

日曜日の朝、お母さんが子どもに言いました。

「お昼までに、お部屋をきれいにしてね」

子どもは、床にちらばったおもちゃを箱に入れて、「できたよ！」と言いました。
ところが、お部屋をのぞいたお母さんはがっかりです。
「えっ、まだ掃除機もかけてないし、机の上も散らかったままじゃない」

さて、ここで質問です。**悪いのは、どちらでしょう？**

子どもは、ウソをついていません。子どもにとっての「きれい」は、「床におもちゃがない」ことでした。
お母さんも、まちがったことは言っていません。お母さんにとっての「きれい」は、「床も机もすっきりして、掃除機までかけてある」ことでした。

**ふたりとも正しい。でも、見ている「きれい」がちがった。**
これが、思いこみメガネです。

![お母さんと子どもが、それぞれちがう「きれいな部屋」を思いうかべている。メガネをはずしてゴールテープをそろえると、同じ部屋が見える](assets/img/ch00-room.svg)

もし、お母さんがこう言っていたら、どうでしょう。

「お昼の12時までに、①床に物がひとつもない ②机の上は教科書だけ ③掃除機をかけ終わっている。この3つができたら合格ね」

これなら、子どもは迷いません。お母さんもがっかりしません。そして、ちゃんとできた子どもを、心から「すごいね！」とほめられます。

会社の中でも、毎日これと同じことがおきています。
「ちゃんと」「しっかり」「なるべく早く」「いい感じに」――。どれも、人によって見えているものがちがう言葉です。

## ④ 考え方

### 1. 思いこみメガネってなに？

この教材でいう**思いこみメガネ**とは、

> **「本当（事実）」と「自分にはそう見えている（思いこみ）」のあいだにある、ズレのこと**

です。（マネジメントの言葉では「錯覚」といいます）

メガネがくもっていると、まじめな人ほど空回りします。
一生けんめい「自分に見えているゴール」に向かって走るのに、それが上司の見ているゴールとちがうからです。
そして、がんばったのに認められないと、人はやる気をなくしてしまいます。

だから、この教材で私が伝えたいのは、**「もっと気合いを入れよう」ではありません。**
**「見え方をそろえる仕組みをつくろう」**ということです。

### 2. くもったメガネが生む3つのムダ

| ムダ | どんなこと？ | こむぎベーカリーの例 |
|---|---|---|
| 🔁 **やり直しのムダ** | できあがりがちがうので、作り直しになる | 「パンを多めに焼いて」と言われた職人さんが、いつもの1.2倍を焼いた。店長は2倍のつもりだった。お昼にパンが売り切れて、あわてて焼き直し |
| 😮‍💨 **気持ちのムダ** | 「言った・言わない」「わかってくれない」で心がつかれる | 社長が店員さんに直接お願いしたことを、店長が知らない。店長は「自分は信用されていない」と感じてしまった |
| 🙈 **言い訳のムダ** | 失敗の理由さがしに時間を使う | 開店準備が間に合わなかった理由を、店と工場がおたがいのせいにして、30分話しあった。でも次にどうするかは決まらなかった |

どれも、だれかがサボっているわけではありません。**見え方がそろっていないだけ**です。
そして、この3つのムダは、会社が大きくなるほど増えていきます。

### 3. よくある思いこみメガネは、だいたい決まっている

おもしろいことに、会社の中の思いこみメガネには「よくある形」があります。
私はたくさんの会社を見てきましたが、ほとんどの会社で、同じメガネがくもっています。
この教材の章は、そのメガネを1つずつはずしていく順番に並んでいます。

![5つの思いこみメガネ：自分の席・約束・ゴールテープ・点数・距離と言葉。それぞれが教材の章につながっている](assets/img/ch00-five-glasses.svg)

| よくある思いこみメガネ | 本当は… | はずす章 |
|---|---|---|
| 「上司と部下は、なかよしの横並びがいい」 | 自分の席と報告の道すじがはっきりしていると、だれも迷わない | 第1章 自分の席はどこ？ |
| 「言わなくても、ふつうはわかる」 | 「ふつう」は人の数だけある。約束は紙に書いて、はじめてそろう | 第2章 チームのルールブック |
| 「がんばってね、で伝わる」 | 頼むときに「できあがりの姿」と「しめきり」を先に決める | 第4章 ゴールテープを先に引く |
| 「がんばった人をほめるのが、いい評価」 | がんばりは見る人によってちがう。届けた「できあがり」で点数をつける | 第5章 点数は「できあがり」でつける |
| 「仲がよいほど、チームは強い」「熱く話せば伝わる」 | ちょうどいい距離と、事実で話す習慣が、チームを強くする | 第7章・第8章 |

### 4. メガネをはずすと、冷たい会社になる？

ここまで読んで、こう思った方もいるかもしれません。

「ルールを決めて、できあがりで点数をつけるなんて、なんだか冷たい会社にならない？」

私も最初はそう思っていました。でも、実際はその反対です。

横断歩道を思いうかべてください。
白い線と信号があるから、私たちは安心して道をわたれます。もし線も信号もなかったら、毎回「いま、わたっていいのかな？」とドキドキしながら、車の運転手さんの顔色をうかがうことになります。

**ルールは、人をしばるための線ではありません。迷わないための線です。**

- 約束がはっきりしていれば、それを守っている人は、だれからも責められません
- できあがりで点数がつけば、上司の「好き・きらい」で評価が変わることがありません
- 自分の席がはっきりしていれば、「これ、だれがやるの？」で止まることがありません

メガネをはずしたチームは、**やさしくて、わかりやすいチーム**です。
社長が顔色をうかがわれるチームでも、社員さんが顔色をうかがうチームでもなく、**みんなが同じゴールテープを見て走るチーム**です。

### 5. この教材の地図

この教材には、2つのコースがあります。

| コース | だれのため？ | 中身 |
|---|---|---|
| 🛠️ **つくる人のコース** | 社長・役員・店長・リーダーなど、ルールや成長シートを**つくる人** | 第0章〜第11章。最後に「わが社の成長シート」ができあがる |
| 🌱 **使う人のコース** | 社員さん・パートさん・新人さんなど、ルールや成長シートを**使う人** | S0〜S4の5章（約1時間半）。読んで・クイズに答えて・自分の目標を1つ書く |

つくる人のコースの道のりは、こうなっています。

| ステージ | 章 | 必修 |
|---|---|:-:|
| はじめに | 0 思いこみメガネをはずそう | ★ |
| 1 席と約束をそろえる | 1 自分の席はどこ？／2 チームのルールブック／3 任された範囲と使える道具 | 1・2が★ |
| 2 ゴールと点数をそろえる | 4 ゴールテープを先に引く／5 点数は「できあがり」でつける／6 「でも・だって」の逃げ道をふさぐ | 4・5が★ |
| 3 人と人の間をそろえる | 7 上司と部下のちょうどいい距離／8 「気持ち」と「事実」を分けて話す／9 チームが勝つと自分も勝つ | |
| 4 形にしてまわす | 10 わが社の成長シートをつくる／11 90日まわしてみよう | ★ |

**まずは★の7章だけで大丈夫です。**
この7章を終えると、あなたの会社の「成長シート」と、それを90日まわす手順がそろいます。
残りの章は、このあとの診断で点数が低かった分野から選んで進めてください。

> 💡 **社員さんには、使う人のコースを**
> つくる人のコースを進めながら、社員さんには使う人のコースを読んでもらうのがおすすめです。
> 上司と部下が同じ言葉（「ゴールテープ」「自分の席」など）を使えるようになると、それだけでメガネのくもりがぐっと減ります。

### 6. 進めるときの3つのコツ

1. **まず、自分のメガネから**
   この教材で最初にはずすのは、社員さんのメガネではなく、**社長と上司のメガネ**です。「伝わっていない」と感じたら、「伝え方に、ゴールテープはあったかな？」と自分に聞いてみてください。私も、いまだに毎週のようにこれをやっています。
2. **100点を目指さない**
   最初は「とりあえず」で大丈夫です。約束も成長シートも、使いながら直していくものです。
3. **しめきりを決める**
   この教材を進めること自体にも、ゴールテープを引きましょう。「2週間に1章」がおすすめです。

## ⑤ ワーク

### ワーク1：モヤモヤ診断

いまの会社の状態で、正直に答えてください。
「できている＝2点」「少しできている＝1点」「できていない＝0点」です。

**理想ではなく、いまの本当の姿で**答えるのがポイントです。
点数が低くても大丈夫。低いところは、メガネのくもりが見つかった場所。これから一番スッキリするところです。

```work
id: 00.diag
type: scale
label: モヤモヤ診断
scale: [{value: 2, label: できている}, {value: 1, label: 少しできている}, {value: 0, label: できていない}]
groups:
  - name: 自分の席
    items:
      - だれが、だれに報告するのかが、図や表になっていて、全員が知っている
      - 社長や上の人が、間の上司を飛びこえて、直接仕事を頼むことはほとんどない
      - 部下から見て「自分の上司はこの人ひとり」と、はっきり言える
      - 「これ、だれがやるの？」で仕事が止まることは、ほとんどない
  - name: 約束
    items:
      - 挨拶・しめきり・報告のしかたなど、「だれでも守れる約束」が紙に書いてある
      - その約束を、上の人ほどしっかり守っている
      - 約束が守られていないとき、その場で、だれが言っても同じように声をかけている
      - 新しく入った人が、最初の週に約束を教わる流れがある
  - name: ゴールテープ
    items:
      - 仕事を頼むとき、「何を・いつまでに・どうなっていたら合格か」を伝えている
      - しめきりは「日付と時刻」まで決めている
      - 頼まれた人が、できあがりの姿を自分の言葉で言いなおせる
      - 「ちゃんと」「しっかり」「なるべく早く」で仕事を頼むことは、ほとんどない
  - name: 点数
    items:
      - 役職ごとに「何ができたら合格か」を書いた表（成長シートなど）がある
      - 点数は、がんばりや人柄ではなく、届けた「できあがり」でつけている
      - 社員さんが「次に何ができたら、1段上がれるか」を知っている
      - 点数をつけた理由を、事実（数字・日付・できあがったもの）で説明できる
  - name: 距離と言葉
    items:
      - 上司が部下と仲よくなりすぎて、注意や点数づけをためらうことはない
      - 報告は「結論から」「事実と気持ちを分けて」話す習慣がある
      - 失敗の報告が「でも・だって」ではなく「次はこうします」で終わる
      - 会議で、「たぶん」「〜と思う」ではなく、数字や事実をもとに話している
```

| 11〜20点 | 🌥️ **ところどころ、くもり**：そろっているところと、そうでないところがある | ★の7章を順番に。すでにできているところは「確かめ」のつもりで |

### ワーク2：わが社の「ズレ事件」

最近おきた「言ったつもり・聞いたつもり」の出来事を、1つ思い出してください。
だれかを責めるためではなく、**メガネのくもりを見つけるため**に書きます。

```work
id: 00.zure
type: form
label: わが社の「ズレ事件」メモ
fields:
  - {key: said, label: ① 頼んだ人は、なんと言いましたか？, type: textarea}
  - {key: heard, label: ② 頼まれた人には、どう伝わっていましたか？, type: textarea}
  - {key: result, label: ③ その結果、何がおきましたか？, type: textarea}
  - {key: tape, label: ④ もし最初に「ゴールテープ」を引くとしたら、なんと言えばよかったですか？, type: textarea}
hint: ②は想像でかまいません。できれば、頼まれた本人に「あのとき、どう受けとっていた？」と、やさしく聞いてみてください。思ってもみなかった答えが返ってくることがよくあります。
example:
  said: 「明日の駅前店の朝の分、パン多めに焼いといて」（社長 → 工場の職人さん）
  heard: 職人さんは「いつもより少し多め」と受けとり、いつもの1.2倍を焼いた。
  result: 社長は2倍のつもりだった（駅前でお祭りがあった）。お昼前に売り切れて、店長が工場に電話。あわてて焼き直したが、いちばん売れる時間に間に合わなかった。
  tape: 「明日の朝7時までに、駅前店の分を、いつもの2倍（食パン40本・惣菜パン160個）焼いて届けてほしい。お祭りがあるから」
```

## ⑧ 次の章へ

メガネをはずす最初の一歩は、**「自分の席」をはっきりさせること**です。

サッカーを習いはじめたばかりの子どもたちの試合を見たことはありますか？
全員がボールに集まって、だんごのようになって走りまわります。みんな一生けんめいなのに、なかなか点が入りません。
それは、**自分のポジション（席）がわかっていない**からです。

会社でも同じです。だれが、だれに報告して、どこまでを受けもつのか。
次の**第1章「自分の席はどこ？」**では、わが社の「席の地図」をつくります。

### 問いかけの例
- 「この1週間で、『ちゃんと』『しっかり』を何回使いましたか？」
- 「社員さんに、いま一番がんばっていることを聞いたら、社長が思っていることと同じ答えが返ってきそうですか？」
- 「あなたの会社で『言わなくてもわかるでしょ』が一番多いのは、どんな場面ですか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 「うちの社員は、やる気がないんです」と、社員さんのせいにする | ズレ事件を一緒に書いてみる。多くの場合、④のゴールテープがなかったことに本人が気づく |
| 「ルールで縛るのは、うちの社風に合わない」 | 横断歩道のたとえ。ルールは迷わないための線で、守っている人を守るもの、と伝える |
| 理想の状態で答えてしまい、点数が高く出る | 「社員さんに同じ診断をしてもらったら、同じ点数になりそうですか？」と聞く。実際に社員さんにも答えてもらうと、ズレそのものが見えておすすめ |
| 点数が低くて落ちこむ | 低いところは「くもりが見つかった場所」。第11章で比べるのが楽しみになる、と伝える |
