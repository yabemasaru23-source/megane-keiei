## ① この章でできるようになること

- 「気持ち・意見」と「事実」を見分けて、気持ちの言葉を、だれが聞いても同じになる事実の言葉に書きかえられるようになる
- わが社の「報告のかたち（4ステップ）」を決めて、報告・会議・注意・面談を「まず事実をそろえてから、意見を言う」順番で進められるようになる
- 悪い報告ほど早く届くように、上司が「受けとり方の約束」を決められるようになる

## ② 思いこみメガネ、かけていませんか？

> 🦉 **思いこみメガネ**
> 「熱く話せば、気持ちは伝わる。思いが強い人の意見のほうが、きっと正しい」

### こんなこと、ありませんか？

- 会議が「最近、お客さんが減ってる気がする」「みんな、がんばってはいるんですけど」で終わり、何も決まらない
- 声の大きい人や、熱心に話す人の意見で決まる。あとで数字を見たら、まったく逆だった
- 部下を注意するとき、つい「やる気あるの？」「なんでいつもそうなの？」と言ってしまい、相手はだまりこむか、むっとする
- 報告が「たぶん大丈夫です」「けっこう売れました」で、結局どうなっているのかわからない
- 悪い知らせほど、いちばん最後に、いちばん大きくなってから届く

こむぎベーカリーの店長会議も、まさにこうでした。
月に1回、社長と3人の店長、工場長が集まります。社長が「最近どう？」と聞くと、公園通り店の店長が言いました。
「最近、お客さんが減ってる気がするんですよね……」
ショッピングモール店の店長も続けます。「うちも、みんながんばってはいるんですけど……」
社長は「そうか、みんなでもっと気合いを入れていこう！」と熱く話し、会議は60分で終わりました。

**何が減っていて、何をすればいいのか。だれにもわからないまま**です。
次の月の会議でも、ほとんど同じ話がくり返されました。

だれもふざけていません。店長たちは本気で心配していますし、社長も本気でみんなを元気づけようとしています。
でも、**気持ちはたくさん話されたのに、事実がひとつも出てこなかった**のです。

> 🦉 **本当は…**
> 気持ちは、人の数だけある。でも、事実はひとつ。
> だから、**まず事実をそろえて、そのあとで気持ち・意見を出し合う。**
> 熱い気持ちは、事実の上にのせたときに、いちばんまっすぐ伝わる。

### 目指す姿

| いま（気持ちで話すチーム） | 目指す姿（事実から話すチーム） |
|---|---|
| 会議が「〜な気がする」「がんばってます」で終わり、何も決まらない | 会議の最初に事実（数字・日付・起きたこと）がそろい、時間内に「次にやること」が決まる |
| 声の大きい人・熱く話す人の意見で決まる | 事実をもとに、一つ上の席の人が決める。声の大きさでは決まらない |
| 注意が「やる気あるの？」になり、相手が心を閉じる | 注意は「今週、開店準備が3日遅れた」と事実で伝え、「次はどうする？」で前を向く |
| 報告がだらだら長く、「で、どうなったの？」と聞き返す | 報告は「〇〇の件です」から始まり、結論 → 事実 → 次にやること、の4ステップ |
| 悪い知らせが、大きくなってから届く | 悪い知らせほど早く届き、上司の最初のひとことは「早く言ってくれてありがとう」 |

## ③ たとえ話：理科の観察カードと、サッカーのビデオ判定

### 理科の観察カード

小学校の理科で、豆やヒマワリのたねをまいて、観察カードを書いたことはありませんか？

同じ日に、同じたねをまいた、2人の観察カードを見てみましょう。

- Aさんのカード：「すごく伸びた！ 葉っぱも元気そう！ うれしい！」
- Bさんのカード：「10月3日から10月6日の3日間で、2cm伸びた（3cm → 5cm）。葉は2枚から4枚になった」

先生がクラスのみんなに聞きました。
「水を毎日あげた鉢と、2日に1回あげた鉢。どっちがよく育ったかな？」

Aさんのカードでは、答えられません。「すごく」が、どのくらいなのかわからないからです。
となりの子のカードにも「すごく伸びた！」と書いてあったら、もうお手上げです。
Bさんのカードなら、すぐに比べられます。だれが読んでも「3日で2cm」は「3日で2cm」です。

でも、Aさんの「うれしい！」は、まちがいでしょうか？
いいえ、とても大切な気持ちです。だから、多くの観察カードには、**「記録」の欄と「気づいたこと・思ったこと」の欄が、別々に**つくってあります。
先に記録（事実）を書いて、そのあとに思ったこと（気持ち）を書く。**まぜないで、分けて書く。**
これだけで、カードはクラスのみんなで比べられる、役に立つ記録になります。

### サッカーのビデオ判定

もう1つ、サッカーの試合を思いうかべてください。

ゴール前でボールがこぼれ、シュートが入りました。
ところが、守っていたチームの選手たちが審判をとりかこみ、大きな声で「いまのはオフサイドだ！」とうったえます。観客席からも、ものすごい声がとびます。

プロの試合では、こういうとき**ビデオ判定**をします。
審判は、選手の声の大きさでも、観客の熱さでもなく、**映像（事実）を見て**決めます。
どんなに熱くうったえても、映像でオフサイドでなければゴール。どんなに静かでも、映像でオフサイドならノーゴールです。

もし、**声の大きいチームの言うとおりに判定が決まる**としたら、どうなるでしょう。
次の試合から、どちらのチームも、プレーよりも「大きな声でうったえる練習」をするようになってしまいますよね。

会社の会議も、まったく同じです。

## ④ 考え方

### 1. 「事実」と「気持ち・意見」

この教材では、話す言葉を2つに分けて考えます。

| | 📏 **事実** | 💭 **気持ち・意見** |
|---|---|---|
| どんな言葉？ | **だれが見ても同じこと**。数字・日付・時刻・起きたこと | **その人に見えていること・感じていること**。「〜と思う」「〜な気がする」「たぶん」 |
| たとえば | 「10月の来店数は、1日平均176人だった」 | 「最近、お客さんが減ってる気がする」 |
| 人によって変わる？ | 変わらない | 変わる（それがふつう） |
| 使いみち | みんなで同じものを見るための**土台** | 次にどうするかを考えるための**材料** |

（マネジメントの言葉では、気持ち・意見のことを「主張」といいます）

大事なのは、**気持ち・意見が悪いわけではない**ということです。
「お客さんが減っている気がする」という店長のアンテナは、とても大切です。それがなければ、だれも数字を調べようとしません。
困るのは、**気持ちだけで話が終わってしまうこと**と、**気持ちと事実がまざって、どれが事実かわからなくなること**です。

見分け方はかんたんです。自分の言葉に、こう聞いてみてください。

> **「それは、何を見てそう思ったの？」**

答えに数字・日付・起きたことが出てきたら、それが事実です。何も出てこなかったら、それはまだ気持ちです。

| 💭 気持ちの言葉 | 何を見てそう思った？ | 📏 事実の言葉 |
|---|---|---|
| 最近、お客さんが減ってる気がする | 夕方のお店が、がらんとしている | 10月の来店数は1日平均176人で、9月（181人）とほぼ同じ。でも17時以降は、1日31人から19人に減った |
| みんな、がんばってはいるんですけど | 毎日、閉店まで残ってくれている | 10月の廃棄は売上の7.2%。目標の5%を、4か月続けてこえている |
| 新作のパン、評判いいですよ | お客様に「おいしい」と言われた | 発売から1週間で312個売れた。7日のうち4日は、15時前に売り切れた |
| あの子は、やる気がない | 朝、あわてて準備している | 今週、開店準備が7時30分に間に合わなかった日が3日あった（月・水・金） |

いちばん下の行を見てください。
「やる気がない」は、人柄の話です。言われた人は、何を直せばいいのかわかりません。
「今週、3日間に合わなかった」は、仕事の話です。言われた人は、「次は間に合わせる」と、やることがはっきりわかります。

### 2. 順番がすべて――まず事実、それから気持ち

では、気持ちはどこで話せばいいのでしょう。
答えは、**事実のあと**です。観察カードの「記録」の欄と「思ったこと」の欄と同じです。

![熱さで決まる会議では「気がする」「がんばってます」という気持ちの言葉が大きな声でぶつかり、何も決まらない。事実から始める会議では、まず数字の表で事実をそろえ、次に「私はこう思う」と意見を出し合い、最後に一つ上の席の人が決める](assets/img/ch08-fact-first.svg)

| 順番 | すること | こむぎベーカリーの店長会議では |
|---|---|---|
| ① **事実をそろえる** | 数字・日付・起きたことを、全員で同じものを見る | 3店の10月の来店数・売上・廃棄の表を、全員が手もとに持つ |
| ② **気持ち・意見を出す** | 事実を見て、どう思うか・どうしたらいいかを出し合う | 「17時の棚が少なすぎるからだと思います。17時に24種類中9種類しか残っていませんでした」 |
| ③ **決める** | 一つ上の席の人が、事実と意見をもとに決める | 社長が「公園通り店は、夕方用の食パンと惣菜パンを足して2週間ためす」と決める |

①を飛ばして②から始めると、「私はこう思う」「いや、私はこう思う」と、気持ちと気持ちのぶつかり合いになります。
気持ちと気持ちは、比べられません。だから、最後は**声の大きい人や、えらい人の気持ち**で決まってしまいます。

①を先にすると、ふしぎなことがおきます。
全員が同じ事実を見ているので、意見のちがいが小さくなります。そして意見がちがうときも、「同じ数字を見て、どう考えるかがちがう」だけなので、落ちついて話せるのです。

> 💡 **熱さは、事実のあとで**
> 熱く話すことを、やめる必要はありません。思いの強さは、チームを動かす大きな力です。
> ただし、**「ここからは私の気持ちですが」と、ひとこと分けてから**話します。事実の上にのった熱さは、聞く人の心にまっすぐ届きます。

### 3. わが社の「報告のかたち」――4ステップ

事実から話す習慣を、いちばん毎日使う場面で型にしたのが**報告のかたち**です。
社員さん向けの**S3「報告は『事実』から」**で学ぶのと、まったく同じ4ステップを、会社の型にします。

| ステップ | 言うこと | 例（店長が社長へ、週の売上の報告） |
|---|---|---|
| ① **前おき** | 何の件か | 「公園通り店の、先週の売上の件です」 |
| ② **結論** | どうなったか | 「目標に8万円とどきませんでした。目標140万円に対して、132万円です」 |
| ③ **事実** | 数字・時刻・起きたこと（3つまで） | 「17時以降の来店が、1日平均19人で、先月より12人少なかったです。17時の棚には、24種類のうち9種類しか残っていませんでした。平日5日のうち4日、16時前に食パンが売り切れました」 |
| ④ **次にやること** | これからどうするか | 「今週から、15時の注文で、夕方用に食パン10本と惣菜パン30個を足します。来週月曜の週報で、17時以降の来店数を報告します」 |

この4ステップは、第2章の約束3番「報告は『〇〇の件です』から始め、結論を先に言う」を、もう一歩くわしくしたものです。①が「〇〇の件です」、②が「結論を先に」にあたります。

> 💡 **「理由」は、③の事実の中で言う**
> 「なぜそうなったか」を伝えたいときは、③の事実の中に、**理由になる事実**を入れます。上の例では「17時の棚に9種類しか残っていなかった」が、それにあたります。
> 「たぶん天気のせいだと思います」のような気持ちの理由は、聞かれたときに「ここからは私の考えですが」と分けて言います。

この型は、口で話す報告だけでなく、**週報・電話・メッセージ・会議の発表**にも、そのまま使います。
同じ型を全員が使うと、上司は「どこに何が書いてあるか」を迷わずに読めますし、部下も「何から話せばいいか」を迷いません。

上司が気をつけることは、1つだけです。
**部下が②の結論を言う前に、口をはさまない。**とちゅうで「なんで？」と聞きはじめると、報告は気持ちの言い合いにもどってしまいます。最後の④まで聞いてから、事実を確かめる質問をします。

### 4. 会議は「事実をそろえる → 意見 → 決める」

会議こそ、思いこみメガネがいちばんくもりやすい場所です。
声の大きさ、話のうまさ、その日の気分――。気持ちの力で決まってしまう材料が、たくさんあるからです。

サッカーのビデオ判定を思い出してください。**判定は、映像（事実）で決める。**会議も同じにするための、5つのルールです。

| ルール | どういうこと？ | なぜ？ |
|---|---|---|
| ① **事実は、会議の前に紙で配る** | 数字や記録は、前の日までに1枚にまとめて全員に配る | 会議の時間を、数字をさがす時間にしない。全員が同じ事実を持って席につける |
| ② **最初は、事実だけ** | 会議の最初の時間は、事実の確かめだけ。意見はまだ言わない | 事実がそろう前に意見を言うと、気持ちのぶつかり合いになる |
| ③ **意見には、もとにした事実をつける** | 「私は〜と思います。もとにした事実は〜です」の形で言う | 意見どうしを、同じ土台の上で比べられる |
| ④ **順番に、1人ずつ** | 意見は、席の順に1人ずつ言う。声の大きい人から話さない | 静かな人の意見にも、大事な事実がかくれている |
| ⑤ **決めるのは一つ上の席の人。決まったら全員で動く** | 最後は、その仕事を任されている一つ上の席の人が決める。決めたことは、だれが・何を・いつまでに、の形で読みあげる | 第1章の「決まる前は意見を言う。決まったら動く」と同じ。決めたことは、次の会議の最初の「事実」になる |

こむぎベーカリーの店長会議は、このルールでこう変わりました。

| | いままでの店長会議 | 事実から始める店長会議 |
|---|---|---|
| 会議の前 | 準備なし | 前の日の17時までに、各店長が「来店数・売上・廃棄・先月決めたことの結果」を事務に出し、事務が1枚の表にまとめて配る |
| 始まり | 社長「最近どう？」 | 社長「まず表を見ましょう」。15分は事実の確かめだけ |
| 話し合い | 「気がする」「がんばってます」が60分続く | 「私は〜と思います。もとにした事実は〜」を1人ずつ |
| 終わり | 「気合いを入れていこう！」 | 「公園通り店は、夕方用のパンを足して2週間ためす。11月18日の会議で、17時以降の来店数を見る」と社長が決める |

### 5. 注意するときも、事実で

部下に注意するとき、いちばんやってしまいがちなのが、**気持ちの言葉で注意する**ことです。

「やる気あるの？」「たるんでるんじゃない？」「なんでいつもそうなの？」

言っている上司は、本気で心配しています。でも、言われた部下には、**「自分という人がダメだ」と言われた**ように聞こえます。人は、人柄を責められると、心を閉じるか、言い返したくなります。そして、何を直せばいいのかは、少しもわかりません。

注意するときは、**人ではなく、事実に光をあてます。**3つの順番で話します。

| 順番 | 言うこと | 例 |
|---|---|---|
| ① **見た事実** | いつ・何が・どれだけ | 「今週、開店準備が3日、7時30分に間に合わなかったね。月・水・金で、7時30分の棚は24種類のうち18〜20種類だった」 |
| ② **約束（ゴールテープ）とのちがい** | 決めていたことと、どこがちがうか | 「開店準備のゴールテープは、7時30分に24種類が値札つきでならんでいること、だったよね」 |
| ③ **次はどうする？** | 本人に考えてもらう | 「次の1週間で、間に合わせるには、どうする？」 |

①の事実は、**上司が自分の目で見たもの、記録に残っているもの**だけにします。「〇〇さんが言ってたけど」という、だれかの気持ちをまぜないことがコツです。
そして、「いつも」「ぜんぜん」「みんな」も使いません。「いつも遅れる」ではなく「今週3日遅れた」。数えてみると、本当は「いつも」ではないことも、よくあります。

> 💡 **「その場で」と「事実で」はセット**
> 第2章では、約束が守られていないのを見たら「その場で」声をかける、と決めました。その場で言うからこそ、事実がはっきりしていて、短い言葉ですみます。
> 第5章の「点数の理由は事実で言う」、第11章の面談の「まず事実を見る」も、すべて同じ考え方です。注意も、点数も、面談も、**事実から始める**のがこの教材のやり方です。

### 6. 悪い報告ほど、早く――受けとる上司の約束

最後に、とても大事な話をします。

悪い知らせ――ミス、クレーム、遅れ、目標に届かなそうなこと。これは、**時間がたつほど大きくなります。**
小さな火なら、コップ1杯の水で消せます。でも、気づかれずに燃え広がった火は、消防車を呼ばないと消せません。
「パンが200個足りない」も、前の日の15時にわかれば、工場がすぐに焼きたせます。当日の朝7時にわかったら、もう間に合いません。

それなのに、多くの会社で、悪い知らせはいちばん最後に届きます。なぜでしょう。
**悪い報告をした人が、いちばん怒られるから**です。

一度でも「なんでもっと早く言わないの！」「何やってるの！」と強く言われた人は、次から、悪い報告をするのがこわくなります。
「もう少し自分でなんとかしてから」「怒られなさそうなタイミングで」と待っているうちに、火はどんどん大きくなります。

だから、悪い報告が早く届くかどうかは、**話す部下ではなく、受けとる上司**で決まります。
上司のための、受けとり方の約束です。

| 受けとり方の約束 | どういうこと？ |
|---|---|
| ① **最初のひとことは「早く言ってくれてありがとう」** | 中身を聞く前に、報告してくれたことにお礼を言う。これを毎回、同じように |
| ② **4ステップで、最後まで聞く** | 結論と事実を聞きおわるまで、責める言葉も、ため息も出さない |
| ③ **「なんで？」ではなく「何がおきた？」「次はどうする？」** | 人を責める質問ではなく、事実と次の一歩を聞く質問をする |
| ④ **報告したことで、点数を下げない** | 点数は、いつもどおり「できあがり」でつける（第5章）。早く報告したことは、むしろ「ありがとう」の対象 |

> 💡 **「ありがとう」は、言い訳をゆるすことではない**
> 「早く言ってくれてありがとう」は、ミスをなかったことにする言葉ではありません。できあがりが届かなかった事実は、事実として残ります。
> 言いたいのは、**「早く知らせてくれたおかげで、小さいうちに手を打てる」**ということです。そのうえで「次はどうする？」と、前を向いて話します。（失敗の理由を外に置く「でも・だって」への向き合い方は、第6章でくわしく学びます）

第2章の約束8番「ミスに気づいたら、その日のうちに上司に伝える」は、この受けとり方とセットで、はじめて守られる約束です。
部下に「早く言って」とお願いするなら、まず上司が、**早く言ってよかったと思える受けとり方**をする。ここでも、メガネをはずすのは上の席の人からです。

## ⑤ ワーク

### ワーク1：気持ちの言葉を、事実の言葉に書きかえる

まずは練習です。この1か月で、あなたやまわりの人が使った「気持ちの言葉」を思い出して、事実の言葉に書きかえてみましょう。
会議・報告・注意の中で、よく出てくる言葉から選ぶのがおすすめです。

```work
id: 08.rewrite
type: table
label: 気持ちの言葉を、事実の言葉に書きかえてください
columns: [いつもの気持ちの言葉, 何を見てそう思った？, 事実の言葉（数字・日付・起きたこと）]
hint: まん中の列が書けないときは、まだ事実を見ていないサインです。表や記録を開いて、数字をさがしてみてください。さがしてみたら、思っていたのとちがう事実が出てくることもよくあります。それは大きな発見です。「いつも」「ぜんぜん」「みんな」も、数えて事実に直しましょう。3〜5行書けば十分です。
example:
  - [最近、お客さんが減ってる気がする, 夕方のお店が、がらんとしている, 10月の来店数は1日平均176人で、9月の181人とほぼ同じ。17時以降は1日31人から19人に減った]
  - [みんな、がんばってはいるんですけど, 毎日、閉店まで残ってくれている, 10月の廃棄は売上の7.2%。目標の5%以内を、4か月続けてこえている]
  - [新作のパン、評判いいですよ, お客様に「おいしい」と言われた, 発売から1週間で312個売れた。7日のうち4日は15時前に売り切れた]
  - [工場のパンは、いつも遅い, 朝、パンを待っている時間が長い, 10月の出勤20日のうち、7時15分より遅く届いたのは4日。いちばん遅かったのは7時40分]
```

### ワーク2：わが社の報告のかたち

会社の全員が使う「報告のかたち」を決めます。
4ステップの順番は、S3で社員さんが学ぶものと同じにします。ここでは、**わが社の言葉と、それぞれのステップの決まり**を書きます。

```work
id: 08.format
type: form
label: わが社の報告のかたち（4ステップ）
fields:
  - {key: s1, label: ① 前おき：何の件か（わが社の言い方）, type: textarea}
  - {key: s2, label: ② 結論：どうなったか（言い方の決まり）, type: textarea}
  - {key: s3, label: ③ 事実：数字・時刻・起きたこと（言い方の決まり）, type: textarea}
  - {key: s4, label: ④ 次にやること（言い方の決まり）, type: textarea}
  - {key: sample, label: このかたちで書いた報告の見本（1つ）, type: textarea}
  - {key: where, label: このかたちを使う場面, type: textarea}
hint: 第2章の約束3番「報告は『〇〇の件です』から始め、結論を先に言う」を、4ステップにくわしくしたものです。各ステップの決まりは、短く、だれでも守れる言葉で書きます。見本は、上司への週報や電話など、いちばんよくある報告で書くと、社員さんがまねしやすくなります。でき上がったら、社員さんにはS3「報告は『事実』から」を読んでもらいましょう。
example:
  s1: 「〇〇の件です」から始める。何の話かを、最初の1文で言う。
  s2: 良い知らせも悪い知らせも、結論を先に1文で言う。目標や約束がある仕事は「目標に〇〇とどいた／とどかなかった」の形で、数字もいっしょに言う。
  s3: 数字・時刻・起きたことを3つまで。「〜と思う」「たぶん」「いつも」「みんな」は使わない。なぜそうなったかは、理由になる事実で言う。自分の考えを言いたいときは、最後に「ここからは私の考えですが」と分けて言う。
  s4: 「次は〜します」の形で、いつまでに何をするかを言う。次にいつ報告するかも言う。
  sample: 「公園通り店の、先週の売上の件です。目標に8万円とどきませんでした（目標140万円、実績132万円）。17時以降の来店が1日平均19人で、先月より12人少なかったです。17時の棚には24種類のうち9種類しか残っていませんでした。平日5日のうち4日、16時前に食パンが売り切れました。今週から、15時の注文で夕方用に食パン10本と惣菜パン30個を足します。来週月曜の週報で、17時以降の来店数を報告します」
  where: 上司への報告・相談（口頭・電話・メッセージ）、店長から社長への週報、店長会議の発表、ミスやクレームの報告、工場から店への遅れの連絡
```

### ワーク3：事実から始める会議のルール

あなたの会社で、いちばん大事な定例の会議を1つ選んで、「事実をそろえる → 意見 → 決める」の順番に組みなおします。

```work
id: 08.meeting
type: table
label: 事実から始める会議のルール（会議の名前と、進める順番）
columns: [順番, やること, 時間のめやす, わが社の決まり]
hint: いちばん大事なのは、「会議の前」と「最初は事実だけ」の2つです。事実を会議の前に配っておけば、会議の時間を、数字をさがす時間にせずにすみます。決めるのは、その仕事を任されている一つ上の席の人です（第1章）。決めたことは、第4章のゴールテープ（できあがりの姿・しめきり・確かめるもの）の形で読みあげると、次の会議でそのまま「事実」として確かめられます。
example:
  - [会議の前, 各店長が、来店数・売上・廃棄・先月決めたことの結果を事務に出す。事務が1枚の表にまとめて全員に配る, 前の日の17時まで, 表に書くのは数字と起きたことだけ。感想は書かない]
  - [① 事実をそろえる, 表を見ながら、各店長が数字を読みあげる。ほかの人がしてよいのは「それは何を見て？」の確かめの質問だけ, 15分, この時間は意見を言わない。社長も言わない]
  - [② 意見を出す, 「私は〜と思います。もとにした事実は〜です」の形で、席の順に1人ずつ言う, 25分, 声の大きい人から話さない。人の意見をさえぎらない]
  - [③ 決める, 社長が、事実と意見をもとに決める。決めたことを「だれが・何を・いつまでに」の形で読みあげる, 15分, 決まったら、反対だった人も決めたことで動く]
  - [④ 決めたことを書く, 事務が、決めたことを1枚にまとめて全員に送る。次の会議の表の「先月決めたことの結果」の欄に入れる, 会議の日の18時まで, 次の会議は、この結果の確かめから始める]
```

### ワーク4：注意のしかたを、事実で言いかえる

部下に注意したとき（または、注意したかったのに、だまってしまったとき）を思い出して書きます。
**だれかを責めるためではなく、伝わる言い方を見つけるため**に書きます。

```work
id: 08.scold
type: table
label: いつもの注意を、事実で言いかえてください
columns: [いつもの注意（気持ちの言葉）, 見た事実（いつ・何が・どれだけ）, 約束やゴールテープとのちがい, 事実で言いかえた注意（最後は「次はどうする？」）]
hint: 「やる気」「たるんでる」「いつも」「ぜんぜん」が入っていたら、人柄の話になっているサインです。2列目には、自分の目で見たもの・記録に残っているものだけを書きます。だれかから聞いた話は入れません。3列目が書けないときは、そもそも約束やゴールテープが決まっていないのかもしれません。そのときは、第2章・第4章にもどって先に決めましょう。
example:
  - [やる気あるの？, 今週の月・水・金、7時30分の棚は24種類のうち18〜20種類だった, ゴールテープは「7時30分に24種類が値札つきでならんでいる」, 今週、開店準備が3日、7時30分に間に合わなかったね。7時30分に24種類、がゴールテープだったよね。次の1週間で間に合わせるには、どうする？]
  - [なんでいつも報告が遅いの？, 10月12日のクレームの報告が、次の日の閉店後だった, 約束8番「ミスに気づいたら、その日のうちに上司に伝える」, 12日のクレームの報告が、次の日の夜だったね。約束では、その日のうちだったよね。次に同じことがあったら、どうやって伝える？]
  - [もっとちゃんと片づけて, 10月の閉店チェック表で、トングの洗いもれが3回あった, ゴールテープは「閉店30分後に、トレーとトングが洗って棚にもどっている」, 10月の閉店チェック表で、トングの洗いもれが3回あったよ。閉店30分後に全部洗って棚にもどす、が約束だったね。次はどうしたら、もれがなくなりそう？]
```

### ワーク5：悪い報告の受けとり方の約束

```work
id: 08.badnews
type: form
label: 悪い報告を受けとるときの、上司の約束
fields:
  - {key: first, label: ① 悪い報告を受けたとき、最初に言うひとこと, type: textarea}
  - {key: listen, label: ② 最後まで聞くために、気をつけること, type: textarea}
  - {key: ask, label: ③ 聞きおわったあとに聞く質問, type: textarea}
  - {key: avoid, label: ④ 悪い報告を受けたときに「言わない」と決めた言葉, type: textarea}
  - {key: tell, label: ⑤ この約束を、いつ・だれに伝えますか？, type: textarea}
hint: 悪い報告が早く届くかどうかは、話す部下ではなく、受けとる上司で決まります。④には、自分がついやってしまう口ぐせや、ため息・腕組みなどの態度も書いておきましょう。⑤では、この約束を部下の前で宣言するのがおすすめです。「早く言っても怒られない」とわかるだけで、報告の早さはぐっと変わります。
example:
  first: 「早く言ってくれてありがとう」。中身を聞く前に、毎回これを言う。
  listen: 結論と事実を聞きおわるまで、口をはさまない。ため息をつかない。腕を組まない。メモをとりながら聞く。
  ask: 「何がおきた？」「いま、どこまで手を打った？」「次はどうする？」の3つ。「なんで？」は使わない。
  avoid: 「なんでもっと早く言わないの」「何やってるの」「だから言ったでしょ」。ほかの人と比べる言葉。
  tell: 11月の店長会議で、私（社長）が店長3人と工場長に宣言する。店長たちも、同じ約束を各店の朝礼で店員さんに伝える。
```

## ⑧ 次の章へ

事実で話せるようになると、チームの中で、もう1つ見えるようになるものがあります。
それは、**チームが勝っているか、負けているか**です。

サッカーのビデオ判定で、ゴールが認められた瞬間を思いうかべてください。
よろこぶのは、シュートを決めた選手だけではありません。パスを出した選手も、うしろで守っていたキーパーも、ベンチの選手も、みんなでとびあがってよろこびます。
**チームの1点は、そのまま一人ひとりの1点**だからです。

会社でも、売上や廃棄の数字が事実でそろうと、「チームの勝ち」がだれにでも見えるようになります。
では、その「チームの勝ち」と、一人ひとりの「自分の勝ち」（給料・ほめられること・できることが増えること）は、どうつながっているのでしょう。

次の**第9章「チームが勝つと自分も勝つ」**では、チームの勝ちと自分の勝ちのつながりを、1枚の図にします。

## ⑨ 講師ガイド

### この回のねらい
受講者が「熱く話しても、事実がなければ伝わらない。まず事実をそろえてから気持ちを話す」と腹に落とし、わが社の報告のかたち（4ステップ）と、事実から始める会議のルールを決めること。あわせて、上司が悪い報告の受けとり方を変えると決めること。

### 時間配分（45分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 「最近の会議で、何も決まらずに終わった話題」を1人30秒 |
| 0:05〜0:12 | お話：②③（観察カードとビデオ判定） | 「すごく伸びた！」と「3日で2cm」のカードを読み比べ、「どっちがよく育った？」と聞く。ビデオ判定で「声の大きさで決まらない」を印象づける |
| 0:12〜0:20 | お話：④の1〜3 → ワーク1 | 「それは、何を見てそう思ったの？」の見分け方。2人組で、相手の気持ちの言葉を事実に書きかえる |
| 0:20〜0:28 | ワーク2：報告のかたち | 4ステップの決まりは記入例をもとに。見本の報告を書いたら、となりの人に声に出して読む |
| 0:28〜0:36 | お話：④の4 → ワーク3：会議のルール | 自分の会社のいちばん大事な会議を1つ選び、順番を組みなおす。「最初は事実だけ」をどう守るかを決める |
| 0:36〜0:45 | お話：④の5・6 → ワーク4・5 | 注意の言いかえを1つ書き、2人組で上司役・部下役を1回ずつ。最後に「悪い報告を受けたときの最初のひとこと」を1人ずつ宣言する。ワーク4・5の残りは宿題でよい |

### 問いかけの例
- 「この前の会議で出た話のうち、数字か日付で言えたものは、いくつありましたか？」
- 「『お客さんが減っている気がする』と言われたら、まず何を見に行きますか？」
- 「部下に最後に注意したとき、何と言いましたか？ それは人柄の話でしたか、事実の話でしたか？」
- 「あなたの会社で、悪い知らせは、起きてからどのくらいで社長に届いていますか？ それは、なぜだと思いますか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 「事実ばかりだと、冷たい会社になる」 | 気持ちは、なくすのではなく「事実のあとに、分けて話す」だけ、と伝える。観察カードにも「思ったこと」の欄がある。事実の上にのせた熱さのほうが、まっすぐ伝わる |
| 事実の言葉に書きかえようとしても、数字が見つからない | 数字がないこと自体が大きな発見。記録をとる仕組みがない、ということ。「来店数」「棚の写真」「チェック表」など、まず1つ記録を始めてもらう |
| 「〜と思います」をつけた事実と、本当の意見がまざる（「売上が下がったと思います」） | 「それは表を見ればわかりますか？」と聞く。わかるなら「思います」をとって事実として言う。わからないなら、まだ気持ち |
| 会議で「最初は事実だけ」が守れず、社長がすぐに意見を言ってしまう | いちばん上の席の人ほど、最初の15分はだまっている役、と決めてもらう。社長が先に意見を言うと、ほかの人はその意見に合わせてしまう |
| 注意の事実の中に、「〇〇さんが言ってた」という、ほかの人の話がまざる | 上司が自分の目で見たもの・記録に残っているものだけにする。聞いた話は、まず自分で確かめてから |
| 「早く言ってくれてありがとう」と言うのは、ミスをゆるすようで抵抗がある | ありがとうは、ミスではなく「早く知らせてくれたこと」へのお礼。できあがりが届かなかった事実は、点数でいつもどおりあつかう（第5章）、と分けて伝える |
