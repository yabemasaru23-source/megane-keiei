# 記入例の架空企業：こむぎベーカリー株式会社

> この会社は**架空**です。実在の企業・人物とは関係ありません。
> 全章の記入例はこの1社で統一し、章と章のつながりが見えるようにします。

## 基本情報

| 項目 | 内容 |
|---|---|
| 社名 | こむぎベーカリー株式会社 |
| 事業 | 郊外のパン屋さん3店舗と、パンを焼く工場（セントラルキッチン）1か所 |
| 創業 | 9年前 |
| 社員数 | 28名（正社員12名・パート16名） |
| 売上 | 約2.4億円 |
| 社長 | 麦田 大地（むぎた だいち）／46歳／パン職人出身 |

## チームの形（いま）

```
社長（麦田）
├─ 工場長（1名）── 職人（5名）
├─ 店長A（駅前店）── 店員（6名）
├─ 店長B（公園通り店）── 店員（6名）
├─ 店長C（ショッピングモール店）── 店員（6名）
└─ 事務（1名）
```

## 会社の「いま」の姿（思いこみメガネをかけたまま）

- 社長はみんなと仲よし。休みの日にバーベキューもする。でも、注意しにくい
- 社長が店長を飛びこえて、パートさんに直接お願いすることが多い（店長は「聞いてない」）
- 「ちゃんとやってね」「しっかり頼むよ」で仕事を頼むので、できあがりが人によってちがう
- 店ごとに、挨拶・陳列・閉店作業のやり方がバラバラ
- がんばっている人と、そうでない人の給料がほとんど同じ。がんばる人ほど辞めていく
- 失敗の報告は「でも、工場のパンが遅れて…」「だって、人が足りなくて…」から始まる
- 社長の口ぐせは「言わなくてもわかるでしょ」

## 社長が目指したいこと

- 社長が毎日お店にいなくても、どの店でも同じおいしさと気持ちよさが続く会社にしたい
- がんばった人が、ちゃんと報われる会社にしたい
- 2年以内に4店舗目を出したい

| 章 | 項目 | 記入例 |
